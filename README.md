## 🏗️ The Ecosystem Architecture

DROS is designed around a strict separation of concerns. To demonstrate our commitment to a universal "Semantic Filtering Chip," we have open-sourced the Core Microkernel in 6 different languages. 

### 1️⃣ The Open-Source Core Microkernels (AGPL-3.0)
These repositories contain the reference implementations of the `DROS-RFC-001` Specification. They are ultra-lightweight (300-600 lines of code) and contain zero third-party dependencies.

- ⚙️ **[dros-core-rs](https://github.com/Top-Celestial-Company-Ltd/dros-core-rs)** (Rust): Memory-safe, ultra-high performance.
- 🐹 **[dros-core-go](https://github.com/Top-Celestial-Company-Ltd/dros-core-go)** (Go): High-concurrency cloud runtime.
- ⚡ **[dros-core-cpp](https://github.com/Top-Celestial-Company-Ltd/dros-core-cpp)** (C++): Ultra-low latency bare-metal engine.
- 🐍 **[dros-core-py](https://github.com/Top-Celestial-Company-Ltd/dros-core-py)** (Python): AI-native rapid prototyping environment.
- ☕ **[dros-core-java](https://github.com/Top-Celestial-Company-Ltd/dros-core-java)** (Java): Enterprise cross-platform node.
- 🟦 **[dros-core-ts](https://github.com/Top-Celestial-Company-Ltd/dros-core-ts)** (TypeScript): Isomorphic Node & Browser runtime.
